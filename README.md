# Haojun Jiang — Academic Homepage

Personal academic website for Haojun Jiang (蒋昊峻), focused on AI for healthcare, autonomous robotic ultrasonography, and efficient deep learning.

The site uses the [academic-homepage](https://github.com/luost26/academic-homepage) Jekyll framework. Content is organized into profile data, news items, publication records, and academic activities.

## Local preview

Install Ruby and Bundler, then run:

```bash
bundle install
bundle exec jekyll serve
```

Open the local URL printed by Jekyll.

## Deployment

The repository is ready for GitHub Pages. Configure Pages to deploy from the repository's default branch.
